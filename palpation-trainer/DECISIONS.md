## D-001: データソースは BodyParts3D 一次（A案）— 2026-08-18

- **決定**: メッシュの一次ソースを BodyParts3D Release 4.0（obj_99）とする。Z-Anatomy は不採用（将来の差し替え候補として `AnatomySource` 抽象化で余地を残す）
- **根拠**: Phase 0 検証（PHASE0-VERIFICATION.md）。FMAネイティブ・皮膚全身1枚メッシュ・CC BY 4.0・変換パイプライン実証済み。**ユーザー承認済み（2026-08-18）**

## D-002: anatomy-data パッケージのライセンスは CC BY 4.0 — 2026-08-18

- **決定**: `packages/anatomy-data` のデータライセンスは BodyParts3D の現行ライセンス CC BY 4.0 に合わせる（仕様書 §2.1 の CC BY-SA 4.0 は Z-Anatomy 前提だったため）
- **維持する規律**: 形状改変禁止（フォーマット変換 + Draco のみ）/ アプリからは実行時ロードのみ / 構造単位の帰属表示。SA が外れてもライセンス分離構造は将来の差し替えに備えて維持する

## D-003: 座標系はデータ層で BodyParts3D ネイティブ（Z-up, mm）を保持 — 2026-08-18

- **決定**: GLB は元データの座標系（Z-up・mm・共通ワールド座標）のまま出力する。glTF 標準の Y-up への回転はアプリのビューワー層（シーングループの回転）で行う
- **根拠**: (a) ランドマーク座標（truth.targetLandmarks.center）をネイティブ座標系で一貫管理でき、ベイク時の座標ずれバグを構造的に排除できる。(b) 頂点データ無変換 = 「形状改変ではない」ことが自明になる

## D-004: 筋は「筋概念（左右ペア）」レベルの FMA ID で管理 — 2026-08-18

- **決定**: 構造事実テーブル・採点・scope.json の単位は筋概念レベルの FMA ID（例: 三角筋 FMA32521）とし、BodyParts3D の部位・頭別メッシュ（FJ ファイル、左右別）は scope.json 側で概念に束ねる
- **根拠**: BodyParts3D v4.0 には三角筋・上腕二頭筋・上腕三頭筋・僧帽筋の「全体」メッシュが存在しない（Phase 0 実測）。起始・停止・支配神経の教育も筋レベルで行われる。identification の FMA ID 集合比較は概念レベルで決定論的に成立する

## D-005: 日本語用語は Wikidata（CC0）起点 + 手動補完 — 2026-08-18

- **決定**: nameJa/nameEn/nameLa と FMA/TA98/TA2 の対応は Wikidata SPARQL（構造化データ CC0）から取得し、欠落分と表記検証は『解剖学用語 改訂13版』書籍照合で手動補完。全レコード reviewStatus="draft" で開始し、解剖学教員レビューで "approved" に上げる
- **根拠**: Phase 0 検証（学会公開PDFは日本語のみ・転載禁止。J-GLOBAL/医中誌は規約で機械的取得禁止。Wikidata で取得実証済み）

## D-006: 3D スタックは React 19 + React Three Fiber v9 + drei + Vite — 2026-08-18

- **決定**: §5.4 の推奨どおり React + R3F + drei + GLB を採用。ビルド基盤のみ Next.js ではなく Vite を使用
- **根拠**: 本アプリはクライアント完結（§3.2: 認証・課金なし、ローカル動作で可）で SSR の利点がなく、three.js は本質的にクライアント専用。ビューワーはコンポーネント単位で独立しており、将来 Next.js へ移行する場合も影響は限定的
- **§5.4 判断基準の検証結果**:
  - (b) レイキャストによる座標取得 ✅ — クリック → 皮膚メッシュ交点 → ネイティブ座標(mm)変換 → 肩峰まで 4.2mm の判定を実証
  - (c) レイヤー表示切替 ✅ — 皮膚/筋/骨のトグル動作を確認
  - (a) 60fps ✅（暫定） — 対象 15.3万頂点は Phase 0 検証の余裕範囲。ブラウザペイン非表示環境のため実測は表示環境での確認が残る
- **発見したバグと対処**: three.js のレイキャストは `visible=false` のメッシュも交差判定する → 非表示レイヤーはクリックハンドラ自体を外す実装で対処（テスト済み）
- **付随決定**: 非表示タブ（自動検証・CI）では rAF/ResizeObserver が発火せず R3F が初期化されないため、index.html に hidden 時限定の rAF フォールバックを追加（可視タブでは無効）
