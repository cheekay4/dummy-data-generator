## 1. Z-Anatomy 実データ検証

ソース: github.com/Z-Anatomy/Models-of-human-anatomy（`Z-Anatomy.zip` 82.7MB → `Startup.blend` 292.6MB, Blender 3.5系）。blender-asset-tracer による .blend バイナリ解析（全7,184オブジェクト・1,944コレクション走査）。

- **配布は .blend のみ**（Blenderアプリケーションテンプレート形式）。OBJ/glTF の公式配布なし。ジオメトリ書き出しには Blender のインストールが必要
- **ライセンス**: CC BY-SA 4.0（License.txt / README で確認）。ただし**一部モデルに NC 混在**: 内耳 CC-BY-NC-SA 4.0・腎 CC-BY-NC 4.0（肩領域は非該当だが、構造単位の帰属管理が必須である根拠）。アドオンコードは GPL-3.0
- **皮膚の独立メッシュは存在しない**: skin/integument/cutis/derm を含むオブジェクト0件。Integument系コレクションは全て空ノード。体表面の実体は「9: Regions of human body」= **解剖学的リージョン分割メッシュ299個**（例: `Deltoid region.l/.r`, `Anterior region of arm.l/.r`）
- **FMA ID なし**: オブジェクト名・カスタムプロパティ全走査で "FMA" 0件。命名は TA2 英語名 + サフィックス体系（`.l/.r` 左右、`.j` 結合、`.t/.g` ラベルFONT等）。メッシュ名の89.2%が同梱 TA2.csv（TA2ID + 7言語）と一致
- **神経はメッシュではなくベジェCURVE**（腋窩・筋皮・橈骨・正中・肩甲上神経で実測）。メッシュ化には Blender でのカーブ変換が必要
- 肩〜上腕の抽出は構造上可能: `Left/Right upper limb`（322/381 objs）、`Rotator cuff muscles`（8 MESH）、`Bones of pectoral girdle` 等の多軸コレクションタグで抽出できる

## 2. BodyParts3D 実データ検証

ソース: NBDC LSDB Archive（dbarchive.biosciencedbc.jp）。Release 4.0（2013年、以後更新なし）、`isa_BP3D_4.0_obj_99.zip` 136MB（OBJ 2,234個）を実ダウンロード。

- **ライセンス: 現行は CC BY 4.0**（ライセンスページ 2025-02-25 更新を確認。旧 CC-BY-SA 2.1 Japan は2013年製OBJヘッダに残存するのみ）
- **1構造 = 1 OBJ**、左右別ファイル、全ファイル共通ワールド座標（mm, Z-up, 身長≒1,720mm）→ 読み込むだけで解剖学的位置に整列
- **skin = FMA7163 = 全身1枚メッシュ**（FJ2810.obj、102,467頂点/203,382面、13.8MB）
- FMA ID はインデックスTSV（isa 2,905概念 / partof 1,369件）で全メッシュに対応。**日本語名インデックス（ふりがな付き）も同梱**
- 肩領域カバレッジ実測:
  - ✅ 骨（鎖骨・肩甲骨・上腕骨、左右別）、回旋筋腱板4筋、小胸筋・前鋸筋・菱形筋・肩甲挙筋・烏口腕筋・上腕筋 等
  - ⚠️ 三角筋・上腕二頭筋・上腕三頭筋・僧帽筋は「全体」メッシュなし、**部位・頭別のみ**（三角筋3部・二頭筋2頭・三頭筋3頭。教育上はむしろ利点）。大胸筋全体は partof 側に存在
  - ❌ **骨指標サブメッシュ（肩峰・大結節等）は皆無** → §5.2 の座標ベース採点設計で吸収可能（設計変更不要）
  - ❌ **上肢末梢神経・腕神経叢のメッシュは皆無**（v3.0/v4.0とも。神経メッシュは脳神経系のみ）
  - ❌ **広背筋が v4.0 に存在しない**（v3.0にはあるが座標系が異なり混用不可）

## 3. GLB 変換テスト（実施済み）

obj2gltf 3.2.0 + gltf-transform 4.4.2 で実データを変換:

- 7構造（皮膚含む）全て変換成功。統合 GLB でも**各構造が名前付き独立ノードとして保持** ✅
- **共通ワールド座標が保持され、上腕骨が皮膚内の解剖学的定位置に整列**（bbox 実測で確認）✅
- **Draco 圧縮: 皮膚 4.9MB → 284KB（94%減）、7構造統合 384KB** ✅
- 注意: BodyParts3D は Z-up、glTF 標準は Y-up。obj2gltf は座標をそのまま出力するため、パイプラインで X軸 -90° 回転の補正が必要（軽微）

## 4. 日本語用語データ（§4.3）

- 『解剖学用語 改訂13版』（医学書院 2007, ISBN978-4-260-00073-4, ¥3,960）が最新。TA2対応版・改訂14版は確認できず
- 学会サイト公開データ（anatomy.or.jp/yougo.html）は **PDF・日本語のみ・「無断転載使用禁止」明記** → 機械可読ソースとして使用不可
- **採用推奨: Wikidata SPARQL（構造化データは CC0）**。三角筋・棘上筋・腋窩神経で ja/la/en + FMA/TA98/TA2 の取得を実証済み（3/3ヒット）。肩の筋群（TA98 A04.6.02.*）66件中、日本語ラベルあり45件（68%）
- 不足2〜3割は書籍照合で手動補完（50〜80構造なら現実的）。BodyParts3D 同梱の日本語インデックス（CC BY 4.0）も補助ソースに使える
- **使用禁止ソース**: 学会公開PDF転載、J-GLOBAL / 医中誌シソーラス（規約で機械的取得禁止）、funatoya.com 対応表（All rights reserved）
- FIPAT TA2 公式PDFは「individual terms are within the public domain」と明言 → 個々の用語の採録は低リスク（一般的整理。用語集全体の複製は編集著作物の問題があるため行わない）

## 5. 仕様との食い違い（要指示）

1. **BodyParts3D のライセンスは CC-BY-SA 2.1 Japan → CC BY 4.0 に変更済み**（§2.1 の前提）。SA 条項が消えたため、BodyParts3D を直接使う場合はライセンス分離の制約が大幅に緩む。ただし Z-Anatomy 経由なら Z-Anatomy の CC BY-SA 4.0 が引き続き適用
2. **Z-Anatomy 単体では仕様の前提が2点崩れる**: (a) 皮膚独立メッシュなし（体表はリージョン分割）、(b) FMA ID なし（TA2名のみ、外部CSV対応表で89.2%マッチ）。さらに .blend のみの配布で Blender 導入が必須
3. 神経メッシュは BodyParts3D に皆無、Z-Anatomy はCURVE。→ MVP の神経解答は選択式UI（§6.2）で成立するため実害なし。3D神経表示は将来課題
4. 広背筋が BodyParts3D v4.0 に無い → 症例設計（§7.2）で広背筋を責任筋の主役にしない

## 6. データソース戦略の提案（Phase 1 の前提。指示待ち）

**推奨: A案 — BodyParts3D を一次ソースにする**

| | A案: BodyParts3D 直接（推奨） | B案: Z-Anatomy 一次 |
|---|---|---|
| ライセンス | **CC BY 4.0（SA なし）** | CC BY-SA 4.0 + NC 混在に注意 |
| FMA ID | ネイティブ | なし（TA2名→FMA変換表の自作が必要） |
| 皮膚レイキャスト対象 | 全身1枚メッシュ ✅ | リージョン分割299メッシュ（可能だが複雑） |
| パイプライン | OBJ→GLB **実証済み** | Blender インストール + スクリプト開発が必要 |
| メッシュ品質 | ポリゴン99%削減版（実用上問題ないことを実測確認） | Blender上で修正された高品質版 |
| 神経表示 | 不可 | CURVE→メッシュ変換で将来可能 |

A案でも §2.1 の `anatomy-data` パッケージ分離と `AnatomySource` 抽象化はそのまま維持する（将来 Z-Anatomy や商用データへの差し替え余地のため）。帰属表示は CC BY 4.0 の要件に合わせて更新する。
